# TTALKAK 요금제 개선안 — Jina 리랭커 실측 반영

> **상태: 팀 검토용 제안 (2026-10-11). 최종 가격·제공량 승인 전.**
> 이 문서는 상품 기획과 비용 검증을 위한 것으로, 운영 결제 금액·차단 정책·웹 공개 가격을 변경하지 않는다.

## 1. 근거와 주의점

AI 담당자가 공유한 2026-10-10 로컬 `/query` 실측(develop `a95b733`, `rag-server/WORKLOG.md`, `gemini_usage.json`, `CONTRACT_BACKEND.md`)을 원가 모델의 입력으로 사용한다.

| 구성 | 요청당 토큰 평균 | 측정·추정 요청당 USD |
|---|---:|---:|
| Jina Reranker v3.5 | 8,297 | $0.00015 (v3 공개 단가 적용 추정) |
| Gemini 3.6 Flash 생성(입력·출력·thinking 포함) | 6,643 | $0.00905 |
| Gemini 3.5 Flash Lite 분석 | 1,727 | $0.00098 |
| 합계 | 약 16,668 | 현행 $0.01018 / 2027 정가 가정 $0.01932 |

- 환산 기준: USD/KRW **1,341원/달러** (2026-10-09 종가 근사; 가격 결정 시 환율 재확인).
- 건당 변동 원가: 현행 **약 13.7원** / 2027 가정 **약 25.9원**. 서버 고정비 월 $26(약 34,866원) 별도.
- Jina v3.5 실제 과금 단가·그랜트, Gemini 미래 실제 과금 및 프로모션 여부는 검증 필요.
- 생성 21건, 품질 A/B 12건만으로 **원가 상위 분위수 또는 품질 동등성은 입증되지 않는다**. nDCG@5 0.657→0.609는 관찰된 하락이므로 표본 확대·실제 사용자 만족도 검증 필요.
- Jina 장애 시 CPU torch 폴백은 평균 원가뿐 아니라 지연시간·서버 부담을 바꿀 수 있다.

## 2. 권장 공개 상품 구조 (최종 승인 전 제안)

| 항목 | 비회원 | FREE(로그인) | PRO |
|---|---|---|---|
| 가격 | 무료 | 무료 | **월 9,900원 (부가세 포함 가정)** |
| AI 개선 요청 | **총 3회** 체험 | **월 10회** | **월 150회** |
| 원클릭 개선·Make | 허용된 체험 범위 | 제공 | 제공 |
| 개선 품질 | 동일 파이프라인 | 동일 파이프라인 | 동일 파이프라인 |
| 결과 저장 | 로그인 필요 | 제공 | 제공 |

| 사용량 | 체험 잔여 횟수 | 사용 횟수 + 비용 추적 | 사용 횟수 + 비용 추적 |

**한도 정의:** 사용자 요청으로 새로운 `/query` AI 호출이 실제 시작될 때 1회. 원클릭 개선과 Make의 미리보기/추가 질문/재개선은 공통 풀을 사용한다. 단순 표시·저장·적용·원본 복원·동일 멱등 요청 결과 재조회는 추가 차감하지 않는다. 장애·실패·자동 재시도 시 차감 및 환급 기준은 실제 공급사 과금 기준으로 별도 테스트한다. 미사용 분은 이월하지 않는 안을 권장한다.

- 기존 `4,900원/300회`는 2027 원가 가정에서 **요청 변동비만 약 7,775원**으로 손익이 성립하지 않는다.
- 상품은 FREE/PRO 2단계로 유지해 구현·커뮤니케이션 비용을 줄인다. 추가 가격 구간이나 초과 사용량 구매는 베타 이후 검토한다.
- **월 150회는 평균 지출 가정에 근거한 제안이지, 실제 150회 제공을 현재 백엔드가 보장한다는 뜻이 아니다.**

## 3. 단위 경제성: 월 100명 결제, 무료 500명, 모두 한도 최대 사용한 모델

아래 수치는 보수적 비용 시뮬레이션이며 실제 정산/세무 결과가 아니다.

| 항목 | PRO 결제자 1인당/월 근사 |
|---|---:|
| 부가세 포함 결제 금액 | 9,900원 |
| 매출 공급가액(부가세 10% 가정) | 9,000원 |
| PRO 요청 150회 × 약 25.9원 | −3,887원 |
| 결제 수수료(수수료율 3.5% + 수수료 VAT 10% 가정) | −381원 |
| RAG 서버 $26 ÷ 100명 | −349원 |
| 무료 사용자 5명 × 10회 × 약 25.9원 교차 보조 | −1,296원 |
| **잔여 공헌액(인건비 등 제외)** | **약 3,087원** |

- 매출 공급가액 대비 잔여 공헌액은 약 **34%**. 여기에는 장애·재시도·환불·지원 비용·추가 서버/DB·카드 수수료 계약 차이·환율 변동·법인 세금이 미반영되어 있다.
- 추가 비용을 감안한 운영 여유를 확보하려면 **요청당 원가 +20% 스트레스 테스트** 및 손익 모니터링이 필요하다.
- 유료 가입자 1명당 무료 20명이 각각 월 10회를 최대로 사용하면 이 조건에서는 **손실 가능성**이 있다. 무료 트래픽에 무제한 성장을 가정하지 말고 월 예산 경보·남용 방지 적용 필요.
- 결제 수수료 3.5%는 협약 수수료 확정 전 **기획 가정**이다. 실제 토스 자동결제 계약의 수수료/VAT를 확인해야 한다.

## 4. 구현 필수 조건 및 계측 차이

현재 Spring `RagUsageRecorder` / `TokenCounts`는 `/query`의 `usage.summary/records`를 통해 **LLM 제공자 보고 토큰(생성·분석, 사고 토큰 포함)**을 집계한다. 비용표의 **Jina 리랭킹 8,297토큰은 현재 회원 토큰 합계에 포함된다고 가정하면 안 된다**.

- 평균 LLM 사용량은 약 **8,370토큰/개선**, Jina 합산 전체는 약 **16,668토큰/개선**. 이 둘은 서로 다른 지표다.
- 무료 10회/유료 150회를 실제로 지키려면 **멱등키 기준 요청 횟수 한도**를 새로 검증·구현해야 한다. 현재 `MemberQuotaPolicy`는 토큰 한도만 다루며 `MEMBER_QUOTA_ENABLED` 기본값은 `false`.
- 회원 요청마다 `request_id`를 Spring→RAG `/query`로 전달하고, RAG의 동일 ID 응답 및 `usage`를 요청별로 저장·중복 방지한다. `usage=null`이면 **사용량 미측정**이지 무료 요청이 아니다.
- 공급자별 실제 비용(LLM 입력·출력·사고, Jina, 재시도/폴백)을 별도 계측한다. 리랭킹 토큰을 LLM과 혼동하거나 공급사 모델별 가격 차이를 무시한 토큰 한도만으로 비용을 통제해서는 안 된다.
- 동시 요청 경합, 기간 경계, 멱등 재호출, 부분 성공/오류, 미측정 사용량, API 장애, 게스트 3회 우회 등 경계조건 통합 테스트가 선행돼야 한다.
- 프론트에는 사용자 **요청 횟수**와 사용량을 표시하되, 제공량·가격이 실제 서버 설정과 일치하기 전에는 확정값을 공개하지 않는다.
- 테스트 결제 4,900원 기본값은 **운영 가격이 아니다**. 팀 최종 결정 후 `PRO_MONTHLY_PRICE_KRW`와 백엔드 기본값·문서·UI·테스트를 **동시에** 변경한다. 현재 테스트 전용 결제에서 실제 청구로 전환하지 않는다.

## 5. 배포 승인 전 게이트

1. Jina v3.5 실제 청구 단가·남은 크레딧, Gemini 과금 모델별 현재·2027 단가, 토스 자동결제 계약 수수료 확인.
2. **실패·멀티턴·장문 포함** 최소 수백 건 이상 표본에서 요청당 P50/P90/P99 비용과 품질·지연시간 분포 측정 (표본 수는 목표/변동성에 따라 조정).
3. 100/500/1,000 유료 사용자 및 무료:유료 비율 5:1, 10:1, 20:1에서 손익·서버 부하 재검토.
4. 요청 횟수 차단과 계측 누락 처리, 3회 게스트 정책, 결제 취소·환불, 멱등·동시 요청 테스트.
5. 실제 판매 정책에 대한 팀 승인 후 GitHub 구현 PR 및 CI·스테이징 검증. **본 문서 PR만으로 과금·한도가 변경되지는 않는다.**
