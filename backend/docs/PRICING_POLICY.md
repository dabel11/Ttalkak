# 요금 및 사용량 정책 — 결정 보류

상태: 미확정 (2026-10-10)

## 결정 시점

AI 담당자의 외부 리랭커 평가와 최종 RAG 파이프라인 확정 후, 실제 요청 비용과 서버 자원 사용량을 기준으로 팀에서 결정한다.

현재 검토했던 월 4,900원, 월 30회·300회, 40만·100만 토큰 등의 수치는 확정 정책이 아니다. 공개 요금제 화면에는 가격과 월 제공량이 미정임을 안내한다.

## 유지하는 기능

- 비회원 총 3회 체험과 로그인 후 저장 정책
- 원클릭 개선 및 Make의 기존 API 연동
- 회원별 실제 사용량 조회와 구독 상태 안내
- 기존 테스트 결제 연동

백엔드의 4,900원 기본값과 테스트 데이터의 결제 금액은 기능 검증용이다. 최종 판매 가격을 의미하지 않는다. 이 변경에서는 결제 금액 환경변수, 회원 한도, 한도 활성화 여부를 변경하지 않는다.

## 확정에 필요한 정보

1. 최종 생성·분석·외부 리랭커의 서비스 및 모델, 과금 단위, 적용 기간별 단가
2. 요청별 입력·출력·사고 토큰, 리랭커 호출 수 및 비용, 재시도·대체 호출 비용
3. 단일턴·멀티턴·장문 요청의 평균 및 상위 구간 비용과 품질·응답 시간
4. 외부 리랭커 전환 후 서버 CPU·메모리 사용량
5. Spring에서 호출하는 FastAPI /query의 요청·응답 계약 변경 여부
6. 외부 API 장애 시 처리 방식과 실제 결제 계약 수수료·고정 비용

위 정보로 결제 수수료, 서버 비용, 무료 이용자 비용, 비용 변동 여유를 포함해 가격과 제공량을 산정한다. 토큰 합계와 실제 비용은 모델 및 입력·출력 비중에 따라 달라지므로 별도로 관리한다.
