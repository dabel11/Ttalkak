# 회원 사용 기간 조회 계약

`GET /api/me/usage`는 로그인 회원의 현재 플랜과 기간 내 실제 저장된 사용량을 반환한다. Bearer 인증이 없으면 401 `LOGIN_REQUIRED`이다. 이 응답은 조회 전용이며 결제 등록·갱신·한도 차단을 수행하지 않는다.

```json
{
  "plan": "FREE",
  "periodStart": "2026-09-30T15:00:00Z",
  "periodEnd": "2026-10-31T15:00:00Z",
  "inputTokens": 0,
  "outputTokens": 0,
  "totalTokens": 0,
  "requests": 0
}
```

- FREE: 서울 시간 기준 매월 1일 00:00부터 다음 달 1일 00:00 전까지다. DB에 결제 확인된 PRO 기간이 없으면 기본값은 FREE다.
- PRO: 결제 확인 후 서버 내부에서 등록한 `paid_usage_periods`의 `[startsAt, endsAt)` 동안만 활성화된다. 기간이 끝났다는 이유만으로 자동 갱신하거나 결제하지 않는다.
- PRO가 월중 종료되면 FREE 집계는 PRO 종료 시점부터 시작하여 유료 기간의 토큰을 FREE 사용량에서 제외한다. 다음 달부터 FREE는 다시 월초에 시작한다.
- 결제 확인된 미래 PRO 기간이 현재 FREE 월 안에 시작한다면 FREE 종료 시각은 그 PRO 시작 시각이다.
- 취소 후 남은 유료 기간을 제공하려면 해당 기간을 유지하고 다음 결제 기간을 만들지 않는다. 즉시 환불·권한 회수 시에는 내부에서 해당 기간을 철회해야 한다.
- 현재 API에는 한도·잔여량·결제 상태가 없다. 한도 수치, 결제 제공자와 갱신 정책이 확정될 때 별도 계약으로 추가한다. AI usage가 연결되기 전 사용량은 0으로 표시된다.
