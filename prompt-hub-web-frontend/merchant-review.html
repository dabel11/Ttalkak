결제 경로 안내

현재 실결제는 제공하지 않습니다. 아래 절차는 테스트 키·별도 DB를 사용하는 심사용 환경에서만 확인할 수 있습니다. 운영 사이트에서 요금제가 준비 중으로 표시되는 것은 정상입니다. 이 페이지 자체가 테스트 환경의 개설이나 심사 계정의 생성 완료를 의미하지 않습니다.

  1. 운영자가 별도로 제공한 심사용 주소에서 일반 회원 심사 계정으로 로그인합니다. 계정 ID는 ttalkak_review이며 비밀번호는 별도 전달합니다.
  2. 요금제에서 월 가격과 제공 횟수를 확인하고 상품을 선택합니다. 준비 중으로 표시되면 해당 환경에서 결제 경로를 확인할 수 없습니다.
  3. 테스트 카드 등록창에서 절차를 진행합니다. 실제 카드정보를 입력하지 말고 토스 테스트 결제 안내에 따른 테스트 정보만 사용합니다.
  4. 완료 후 요금제·이용기간·사용량·결제 내역을 확인합니다. 자동 갱신 중단과 환불 요청은 결제 상태 화면에서 확인할 수 있습니다.
  5. 로그아웃 후 다시 로그인하여 상태 유지 여부를 확인합니다. 처리 확인 중인 취소를 재요청하지 말고 안내된 상태를 확인합니다.

서비스·상품 안내 · 환불 정책 · 이용약관 · 개인정보 처리 안내

심사용 비밀번호·API 키는 이 공개 페이지에 게시하지 않습니다. 테스트 결과와 실결제 가능 여부는 별도로 구분합니다.
